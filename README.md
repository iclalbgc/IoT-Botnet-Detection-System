Bu projede, IoT kamera ağ trafiğindeki normal kullanım ile botnet/saldırı trafiğini ayırt etmeyi amaçlıyoruz.
Trafik kayıtlarını Decision Tree, Random Forest ve Logistic Regression algoritmalarıyla sınıflandırıp modellerin performanslarını karşılaştıracağız. 
Ayrıca saldırı ile normal trafiği ayırmada etkili olan özellikleri inceleyeceğiz.
GPT‑4o, tespit sonuçlarını özetleyip analiz bulgularını anlaşılır bir dille açıklamak için kullanılacaktır.
